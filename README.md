Simple Java Calculator

A console-based Java application that performs basic arithmetic operations (Addition, Subtraction, Multiplication, and Division) on two user-input numbers.

Features

• Four Basic Operations: Supports addition, subtraction, multiplication, and division.
• Input Handling: Accepts floating-point values (double) for precise calculations.
• Error Handling: Protects against application crashes by blocking division by zero.

Prerequisites

To run this project, you need to have the following installed:
• Java Development Kit (JDK) (Version 8 or higher)

How to Run

1. Save the code: Save your file as Calculator.java (make sure the class containing your main method is named Calculator).
2. Compile the program: Open your terminal or command prompt and run:bash
javac Calculator.java
Use code with caution.
3. Execute the program: Run the compiled bytecode:bash
java Calculator
Use code with caution.
